## 1. Gapless feasibility and protocol design

- [x] Trace host source staging, decode, packetization, stream IDs, sequence numbers, transport send-ahead, natural EOF, listener scheduler, render ring, Oboe lifecycle, desktop monitor/output, and late-join behavior.
- [x] Write a concise implementation note describing how a track boundary can be represented on the current protocol without stopping/reopening listener output.
- [x] Select the minimum compatible protocol/runtime change needed to keep one sample timeline continuous across track boundaries; document version negotiation and mixed-version behavior. Protocol v3 adds a sample-indexed `TrackBoundary`; peers using v2 remain rejected by strict header validation.
- [x] Define the boundary as contiguous decoded sample indices after conversion to the negotiated PCM format; avoid relying on container duration rounding. The wire event identifies the first sample index of the next entry.
- [x] Define measurable zero-gap/no-overlap thresholds for virtual tests and physical/device acceptance, including the exact diagnostic counters used. Virtual PCM tests require `next.first_sample_index == previous.first_sample_index + previous.frame_count`, zero inserted/overlapped frames, and monotonic packet sequence across each boundary. Device acceptance requires zero output stream close/reopen events at boundaries, zero host boundary discontinuities, and zero listener missing/duplicated sample frames attributable to the transition; collect packet sequence/sample-index, concealment, output open/close, and boundary scheduled/applied counters from host and listener diagnostics.
- [x] Define explicit queue entry and source staging limits based on current per-platform file limits, available storage, memory, and bounded decoder/prebuffer queues. Rust caps a queue at 100 entries and 16 GiB of unique source bytes; each source remains subject to the existing 8 GiB decoder/staging limit, and duplicate entries sharing a source count that source once. Decoder/prebuffer limits remain 8 chunks by default (up to 64).
